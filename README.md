# Proiect-WEB

## Functionalitati gata facute

1. Autentificare completa (inregistrare, login, logout, sesiune persistenta).
2. Diferentiere conturi Student/Profesor in baza de date si afisare corecta in meniu.
3. Meniu utilizator cu dropdown si adaptare vizuala pentru dark mode.
4. Pagina de profesori cu incarcare din baza de date, filtre si carduri.
5. Pagina de documente cu filtre, carduri si actiuni de vizualizare/descarcare.
6. Pagini functionale pentru discutii/comentarii cu integrare date (postari/comentarii).
7. Pagina de profil cu informatii dinamice, editare profil si statistici de activitate.
8. Pagina de setari cu sectiuni (general, notificari, confidentialitate, aspect).
9. Dark mode aplicat global pe site.
10. Branding actualizat cu noile logo-uri din folderul `assets/Logos and icons`.
11. Layout extins pe latime pentru paginile de profesori si documente.
12. Eliminare completa a functionalitatii Team Matching din UI si codul activ.
13. Pagini informative implementate: Contact, Raporteaza problema, Termeni si Conditii, Politica de confidentialitate.

## Functionalitati in curs de finalizare

1. Uniformizare completa UI/UX intre toate paginile (eliminarea stilurilor inline ramase).
2. Finisare copywriting/diacritice pentru consistenta textelor in toate paginile.
3. Curatarea ghidurilor tehnice pentru a reflecta exact structura finala a proiectului.

## Functionalitati neimplementate complet

1. Backend real pentru like/dislike pe recenzii (momentan este simulare in UI pe index).
2. Notificari reale in timp real (stack + persistenta server-side).
3. Sistem avansat de moderare continut (raportare/administrare postari si comentarii).
4. Dashboard administrativ pentru gestionare profesori/documente/utilizatori.
5. Suita de teste automate (unit/integration/e2e) si pipeline CI/CD.
